# 用户认证与权限管理系统 (AuthSystem)

一个专为初学者打造的、结构清晰、无多余黑魔法的**前后端分离 + 三服务端**用户认证管理系统。

---

## 核心特性

- **三服务端分层架构**：
  - **前端静态服务（端口 6031）**：托管纯 HTML/CSS/JS 页面，无任何后端混编。
  - **后端接口服务（端口 8090）**：纯 RESTful JSON API，负责登录、注册、找回密码、密码修改。
  - **数据库代理服务（端口 6070）**：全系统唯一连接数据库的进程，对外提供安全统一的 SQL 执行网关。
- **纯粹的前后端分离（零 session）**：
  - 彻底抛弃复杂的 Flask `session` 与 Cookie 跨域认证。
  - 前端使用浏览器原生 `localStorage` 存储当前用户登录态，直观简单，小白一看即懂。
- **SQLite 与 MySQL 独立分离**：
  - 拥有独立的 `backend/db_sqlite.py`（使用标准 `?` 占位符）。
  - 拥有独立的 `backend/db_mysql.py`（使用标准 `%s` 占位符）。
  - 拒绝在运行期用字符串替换拼凑 SQL 语句。
- **初学者友好代码风格**：
  - 杜绝企业级高阶封装与过长抽象链路，全部使用最基础平实的 Python 与 JavaScript 原生语法编写。
  - 核心功能齐全：账号登录、图形验证码、账号注册、学号找回密码、个人中心修改密码。

## 快速启动

### 1. 安装依赖
确保已安装 Python 3.10 或更高版本，在命令行中执行：
```bash
pip install -r requirements.txt
```

### 2. 一键启动系统
双击根目录下的：
```text
start.bat
```
脚本会自动按顺序启动：
1. 数据库服务（端口 `6070`）
2. 后端接口服务（端口 `8090`）
3. 前端静态服务（端口 `6031`）
并自动在默认浏览器中打开登录页面：`http://127.0.0.1:6031/login`。
