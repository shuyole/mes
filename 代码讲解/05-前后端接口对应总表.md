# 05-前后端接口对应总表

本总表汇总了全系统页面、静态模板、前端脚本、后端接口与数据库操作的端到端映射关系，方便初学者全链路追踪代码执行逻辑。

## 系统数据表结构 (`users` 用户表)

系统核心仅依赖一张结构极为简洁明了的用户表：

```sql
CREATE TABLE IF NOT EXISTS users (
    id INTEGER PRIMARY KEY AUTOINCREMENT,  -- 主键 ID（MySQL 中为 INT AUTO_INCREMENT）
    username VARCHAR(50) UNIQUE NOT NULL,  -- 登录账号名（唯一）
    password VARCHAR(100) NOT NULL,        -- 登录密码
    real_name VARCHAR(50),                 -- 用户真实姓名
    student_id VARCHAR(50) UNIQUE,         -- 学号 / 工号（用于忘记密码时安全核验）
    role VARCHAR(20) DEFAULT 'user',       -- 角色：admin(管理员) 或 user(普通用户)
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP -- 注册时间
);
```
