# 21 · 前端代码讲解（二）：CSS 样式文件（static/css/ 共 18 个）

> 目录：`frontend/static/css/`。采用「公共分层 + 每页同名文件」结构：
>
> | 文件 | 角色 | 被谁加载 |
> |---|---|---|
> | app.css | 基础样式 + 全套组件库（深色工业风） | 所有页面（含登录/改密独立页） |
> | console.css | HUD「指挥中心」皮肤，后加载覆盖 app.css | 所有页面 |
> | base.css | 母版骨架小幅专属样式（.btn-change-pwd、.topbar-title-row、.drawer-loading） | 继承 base.html 的页面 |
> | home.css（原 monitor.css 更名） | 首页大屏看板局部样式 | 仅 home.html |
> | 其余 14 个同名文件 | 每个页面一份的专属样式（line/orders/production/hmi/station_st01/settings/users/recipes/alarms/forbidden/login/register/forgot_password/change_password） | 对应同名 HTML |

加载顺序固定为 **app.css → console.css → base.css（仅母版页）→ 页面 extra_css 同名 CSS**，
后面的文件选择器相同时覆盖前面的规则。独立整页（login/register/forgot_password/
change_password）没有 base.css，顺序为 app.css → console.css → 本页同名 CSS。

## 1. app.css —— 基础样式与组件库

### 1.1 设计变量 :root

集中定义深色工业主题的所有设计令牌，全站统一换色只改这里：

- 背景/面板/文字：`--bg`（近黑深蓝）、`--panel`（面板底色）、`--text`/`--muted`；
- 主题色：`--cyan: #22d3ee`（青色主色，贯穿按钮/边框/发光）、蓝、绿、黄、橙、红语义色；
- 形状：`--radius: 14px`（大圆角玻璃感，console.css 会把它改小成 4px 锐利风格）；
- 阴影：发光阴影（cyan 半透明）、普通悬浮阴影；
- 侧栏/顶栏宽度高度等布局变量。

### 1.2 reset 与全局基础

最小化 reset（box-sizing:border-box、清 margin）；body 用深色底 + CSS 渐变/
`repeating-linear-gradient` 网格纹理背景；统一字体栈（系统无衬线 + 等宽数字字体用于数据）、
滚动条美化（webkit）、选中色、焦点轮廓。

### 1.3 总体布局三件套

- `.app-shell`：`display:grid` 的整页网格 = 固定宽度侧栏 + 右侧工作区；
- `.sidebar`：品牌区 `.sidebar-brand`、导航 `.sidebar-nav`（分组标题
  `.nav-group-caption`、链接 `.side-link` + SVG 图标、active 态左侧高亮条+发光）、
  底部 `.sidebar-footer`；
- `.workspace`：纵向 flex，含 `.topbar`（标题左、控件右）与 `.page-content`（内容滚动区）；
- `.page-heading`：英文眉题 + 大标题 + 右侧上下文说明；`.topbar-controls` 里的时钟、
  用户框 `.user-box`、角色 chip、退出按钮也在此处定义。

### 1.4 按钮体系

- 基类 `.btn`：内边距、圆角、字重、过渡；
- 变体：`.btn-solid`（青色实心主按钮）、`.btn-ghost`/描边按钮、危险红按钮、
  小号 `.btn-sm`；
- 顶栏工具按钮 `.top-tool-btn`、倍速按钮 `.speed-btn`、`.btn-logout`；
- 统一 hover 发光、active 下沉、disabled 半透明。

### 1.5 工具类与面板

- grid 工具类（若干 `.grid-*` 列数类，供卡片快速排版）；
- `.panel` 面板：半透明深色底、1px 青色描边、圆角、标题栏；
- `.stat-card` KPI 卡：大数字（等宽字体）、标签、顶部语义色条、hover 上浮。

### 1.6 表单

label/input/select/textarea 的深色样式（背景、聚焦青色描边发光、placeholder 灰色）、
`.form-row`/`.form-grid` 排列、校验错误态、登录玻璃卡片（登录旧样式也在这里，
登录三页自己的内联 style 再覆盖）。

### 1.7 工具栏、筛选、表格

- `.toolbar`：flex 两端对齐，放筛选按钮组与搜索框；filter 按钮 active 态；
- `table`：深色表格、表头 uppercase 小字、行 hover、斑马纹、边框分隔；
- `.badge` 状态徽标：`.badge-wait`（待生产灰蓝）、`.badge-run`（生产中青/绿脉冲）、
  `.badge-pause`（黄）、`.badge-rework`（橙）、`.badge-done`（绿）；日志级别徽标同理。

### 1.8 工单优先级与进度控件

- 优先级色条：列表行左侧 3~4px 竖条，按 1/2/3 级显示红/橙/灰；
- **进度控件**（对应 _widgets.html 的宏）：`.progress-ctl` 容器、
  `.progress-track`（轨道，相对定位）、`.progress-fill`（填充）、
  `.progress-thumb`（圆形滑块，可拖拽）、`.progress-step`（±按钮）、
  `.progress-meta`（百分比 + 数字输入）、`.progress-stations`（7 工位点亮小点）；
- `.status-ctl` 状态徽标 + `.status-menu` 下拉菜单（绝对定位、阴影、hidden 切换）。

### 1.9 工艺流程与七工位机台图

- `.process-rail`：横向工序轨，节点圆点 + 连线，完成节点变青发光；
- **`.machine.v1` ~ `.machine.v7`**：纯 CSS 画的 7 台不同工位设备，由子元素
  `.arm`（机械臂）、`.head`（作业头）、`.hmi`（小屏）、`.body`（机身）、`.led`
  （指示灯）用不同的宽高/颜色/位置组合区分各工位外形；运行态 led 呼吸、
  arm 位移动画、故障态整体染红。

### 1.10 HMI 与设备区

HMI 布局网格（连接条、安灯、控制区、寄存器表、机械臂卡）；
`.andon-lamp` 三色塔灯（红黄绿，点亮时 box-shadow 发光，未点亮灰暗）；
寄存器表的等宽数字与可写输入；ST01 页的部分通用卡片样式。

### 1.11 日志、选项卡、图表

- `.log-list`：终端风日志流，等宽字体、级别色点、自动滚动视觉；
- `.tabs` / `.tab`：选项卡按钮条与 `.tab-panel` 面板（active 显示）；
- `.chart-box`：Chart.js canvas 的卡片容器与标题。

### 1.12 浮层与反馈组件

- `.modal-mask`：全屏半透明遮罩 + `.modal-box` 居中确认框；
- `.drawer-mask` / `.drawer-content`：右侧滑出的工位诊断抽屉（transform 过渡），
  抽屉内传感器表、参数表、操作按钮；
- `.toast-container`（固定右下角）与 `.toast`（成功绿/失败红/普通青，进场动画，自动消失）；
- `.live-status-pill`（顶栏状态药丸：idle/run/alarm 三色 + 脉冲点）、
  `.sim-speed-box` 倍速选择器。

### 1.13 动画、特殊模式与响应式

- `@keyframes`：呼吸灯（led 明暗）、脉冲（状态点）、传送带移动（线性循环背景位移）、
  toast/抽屉进场、扫描微光；
- `body.scada-fullscreen`：大屏模式（app.js 按 F 时加这个类）——隐藏侧栏、内容铺满、
  字号放大、卡片更亮，适合投屏；
- 媒体查询：`@media (max-width:1200px)` 收紧侧栏与网格列数；
  `@media (max-width:760px)` 侧栏收起为顶部横向滚动、顶栏控件换行、表格允许横向滚动。

## 2. console.css —— HUD 指挥中心皮肤（覆盖层）

在 app.css 之后加载，**不新增组件，只把现有组件「换皮」成更锐利的指挥中心风格**。

### 2.1 变量覆盖

重新声明 `:root`：降低圆角（`--radius: 4px` 直角硬朗风）、换成更锐利的 HUD 青/琥珀配色、
加强描边对比、调整发光强度。因为加载更晚，同名变量在全站生效。

### 2.2 扫描线与氛围

`body::after` 铺一层固定定位的极淡水平扫描线（或重复渐变），配 `hud-scan` 缓慢位移动画，
营造 CRT/SCADA 监控屏质感；内容用层级隔离不挡点击（pointer-events:none）。

### 2.3 区域覆写

- Sidebar HUD：导航改为细描边小面板、active 项四角切角感/角标装饰；
- Topbar：底部加一条高光线、状态药丸加方括号式装饰；
- 面板：`.panel`/`.stat-card` 改为直角 + 角标线条 + 顶部细线，标题用等宽大写字母间距；
- 表格/徽标/按钮：直角化、边框加亮、运行态改线性脉冲；
- Login HUD：登录卡片加角标与扫描线，输入框下划线式；
- Monitor HUD：首页看板的边框、信号点统一成 HUD 语言。

### 2.4 响应式与无障碍

- `@media (max-width:1400px/1100px/760px)`：逐级简化装饰（小屏隐藏扫描线/角标，
  保证内容不被装饰挤占）；
- `@media (prefers-reduced-motion: reduce)`：用户系统开启「减少动态效果」时，
  关闭扫描线、呼吸、脉冲等动画——无障碍设计。

## 3. home.css —— 首页大屏看板（原 monitor.css 更名，仅 home.html）

作用域刻意收窄：选择器以 `body:has(.monitor)` 或 `.monitor ...` 开头，
**只在首页出现 `.monitor` 根节点时生效**，不会污染其他页面。

包含：

- KPI 卡行的等分网格与大数字发光；
- `.station-deck`：7 列等分工位卡（每卡含状态点、机台简形、计数）；
- `.monitor-main`：左右双栏（左遥测列表、右事件流），小屏自动变单栏；
- 遥测列表 `.telemetry` 的标签/值对齐（等宽数字右对齐）；
- 事件流 `.event-feed` 与 `.signal` 脉冲点（数据到达时的亮点动画）；
- 模块化时从模板内联样式补入的局部类：`.monitor-button-demo`（青色演示按钮）、
  `.monitor-kpis--fit`（自适应 KPI 网格）、`.monitor-kpi--oee` / `.kpi-number--oee`
  （OEE 紫卡）、`.line-state-row`。

它最后加载，只对首页布局密度与看板专属元素做精调，颜色/按钮/表格仍复用前两层。
