## 3. 表单字段（name）↔ server.py request.form 对照

| 页面表单 | 提交地址 | 字段 name |
|---|---|---|
| 登录 | POST /login | username、password、captcha |
| 注册 | POST /register | username、student_id、password、confirm_password |
| 找回密码 | POST /forgot_password | username、student_id、captcha、new_password、confirm_password |
| 修改密码 | POST /change_password | old_password、new_password、confirm（账号取自 session） |
| 新建工单 | POST /orders | order_no、product_code、quantity、priority、due_date、remark |
| PLC 设置 | POST /settings → 转发 /api/plc/config | plc_ip、plc_port |
| 用户管理 | POST /users | action（disable/enable/reset/role/delete）、user_id；role 动作额外带 role 值 |

JSON 接口字段（非表单）：/api/orders/<id>/progress 接收
`completed_qty / delta / progress / status / rework_qty`；
/api/line/command 接收 `command / source / order_id`；
/api/plc/config 接收 `ip / port / reconnect`。

## 5. 三类前端文件之间的依赖关系图

```
base.html
 ├─ <link> css/app.css ──────── 基础组件（所有页面）
 ├─ <link> css/console.css ──── HUD 皮肤（覆盖 app.css）
 ├─ <link> css/base.css ─────── 母版专属（改密入口、顶栏、抽屉占位）
 ├─ {% block extra_css %} ───── 每页同名 css/<page>.css
 ├─ <script> js/form.js ─────── 表单校验（全局）
 ├─ <script> window.API_BASE ── 8080 地址（context_processor 注入，内联配置）
 ├─ <script> js/app.js ──────── fetch 代理/心跳/音效/弹窗/抽屉/快捷键（全局）
 ├─ <script> js/base.js ─────── 顶栏时钟与 3 秒轮询 /api/stats
 └─ {% block extra_js %} ────── 每页同名 js/<page>.js：
       home            → home.js
       line            → line.js
       orders          → orders.js + progress.js
       production      → Chart.js CDN + production.js + progress.js
       hmi             → hmi.js
       station_st01    → station_st01.js
       settings/users/recipes/alarms/forbidden → 各自同名 js

orders.html / production.html ── import ── _widgets.html（progress/status 宏）
login/register/forgot_password/change_password → 不继承母版的独立整页，
  各自加载 css/<page>.css 与 form.js + js/<page>.js（粒子背景在各自 JS 内）
```

## 6. 一次完整功能的端到端链路（举例：拖完工单进度）

1. 用户在 /orders 拖动某工单进度滑块（progress.js，Pointer Events + rAF）；
2. 松手时 progress.js 发 `fetch('/api/orders/5/progress', {method:POST, body:{delta:1}})`；
3. app.js 的 fetch 包装器把 URL 改成 `http://主机:8080/api/orders/5/progress`，带 Cookie；
4. api_server 的 login_required 用同一 secret_key + .epoch 验会话，apply_manual_progress 算新进度；
5. db_cursor() 写 production_orders（MySQL 或 SQLite），提交后自动导出 data/sync JSON 快照；
   若正好产线在做这单，还 finish_current_order() 停线、写日志、写 PLC 寄存器；
6. 接口返回最新工单视图 JSON → progress.js 用带序号的响应重绘控件；
7. 3 秒内顶栏 /api/stats 轮询、home 看板轮询自然刷新统计数字。
